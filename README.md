Heyo! Want to make a futuristic keyboard design? Want to know what's even better? This isn't just one keyboard, but two! 

Did you also know that you could make a real-life mouse out of modeling? Check this out!

PR0J3CT: X-CHR0N0 is a split keyboard design shaped like two hands that is compatible for users who want to move their hands around the keyboard instead of typing and sticking on one long keyboard. The design is shaped like a hand so that it works comfortably on the hands while retaining its sleek design.

PR0J3CT: C|ick is a mouse that works just like a real-world mouse, except it isn't designed by manufactrures, it's you!

To build X-CHR0N0, we're using Ki Cad, where we're designing and laying out our parts on the Schematic editor, then we'll switch to the PCB editor to arrange and wire to connect the components.  

To build C|ick, you're going to need this link, https://cad.onshape.com/documents/dc873a91dab732fb6d2334be/w/241c2014482818f7feb51fe4/e/4e6e0c7fa5f4e2a286b91a54, in order to get a pre-edited version of the mouse. You'll realize this is made on Onshape, and we'll design it from here.
