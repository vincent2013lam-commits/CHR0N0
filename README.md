Heyo! Want to make a futuristic keyboard design? Want to know what's even better? This isn't just one keyboard, but two! Check this out!

PR0J3CT: X-CHR0N0 is a split keyboard design shaped like two hands that is compatible for users who want to move their hands around the keyboard instead of typing and sticking on one long keyboard. The design is shaped like a hand so that it works comfortably on the hands while retaining its sleek design.

To build X-CHR0N0, we're using Ki Cad, where we're designing and laying out our parts like the buttons and microcontroller on the Schematic editor, then we'll switch to the PCB editor to arrange and wire to connect the components.
